# Pyure

Локальный офлайн MP3-плеер без рекламы, сети и лишних разрешений.
Работает исключительно с вашей папкой с музыкой на устройстве.

## Поддерживаемые платформы

- **Android (Android 7+)** — **GrapheneOS**, **Samsung (One UI)**, **Honor (MagicOS)**, **Xiaomi / Redmi (HyperOS / MIUI)** и другие Android-смартфоны (`arm64-v8a`, `armeabi-v7a`, `x86_64`).
- **Windows** — **Windows 10** и **Windows 11** (`x64`, необходимые системные библиотеки VC++ включены в установщик).
- **Linux (`x64`)** — **Debian**, **Ubuntu**, **Arch Linux** и **Fedora**.

## Что умеет

- Сканирует выбранную папку и подпапки с MP3, сохраняет библиотеку в локальный кэш SQLite.
- Читает ID3-теги и обложки (встроенные в файл или `cover.jpg` / `folder.jpg` рядом). Если теги пустые, берёт исполнителя и название из имени файла (`Исполнитель - Трек`), а альбом — из имени папки.
- Сортирует альбомы по исполнителю и названию (сначала латиница A–Z, затем кириллица А–Я) и треки по названию, альбому или дате добавления.
- Мгновенно ищет по трекам, исполнителям и альбомам, помнит последний трек, позицию и громкость.
- Надёжно играет в фоне на Android и управляется со шторки уведомлений, экрана блокировки, гарнитуры и аппаратных клавиш / SMTC на Windows.
- На Android открывает музыку через системный Storage Access Framework (SAF): не запрашивает доступ ко всей памяти устройства, а в релизном APK полностью вырезано разрешение `INTERNET`.

## Установка

Готовые сборки лежат на странице [Releases](https://github.com/rcorsar/Pyure/releases):

### Android (GrapheneOS, Samsung, Honor, Xiaomi, Redmi)
Скачайте `Pyure-<версия>-android.apk`, установите APK и при первом запуске выберите папку с музыкой (например `Music`).

### Windows 10 и Windows 11 (x64)
Скачайте `Pyure-<версия>-windows-x64-setup.exe` и запустите установщик.

### Linux (`x64`)
Для системного вывода звука требуется установленный `libmpv` / `mpv` (и портал/диалог выбора папки):

- **Debian / Ubuntu**:
  ```bash
  sudo apt update && sudo apt install ./Pyure-<версия>-linux-x64.deb
  ```
- **Fedora** *(предварительно подключите RPM Fusion Free для пакета `mpv`/`mpv-libs`)*:
  ```bash
  sudo dnf install ./Pyure-<версия>-linux-x64.rpm
  ```
- **Arch Linux**:
  ```bash
  sudo pacman -U ./Pyure-<версия>-linux-x64.pkg.tar.zst
  ```
- **Портативный архив (любой из перечисленных дистрибутивов)**:
  Распакуйте `Pyure-<версия>-linux-x64.tar.gz` и запустите:
  ```bash
  sudo bash install.sh
  ```
  *(или `bash install.sh --user` для установки в `~/.local` без `sudo`)*.
